# 🎵 MusicVerse - Modern Music Education Platform

A high-performance, visually stunning music education platform built with **Next.js 14**, **TypeScript**, and **Aceternity UI**. This application features cinematic animations, responsive course layouts, and a seamless user experience designed for modern music students.

---

## ✨ Key Features

*   **Cinematic UI:** Leverages Aceternity UI for high-fidelity animations including Background Beams, Meteors, and 3D Card effects.
*   **Dynamic Course Catalog:** Fully searchable and categorized music courses managed via JSON data structures.
*   **Interactive Webinars:** Smooth "Card Hover" effects for upcoming sessions with unique routing.
*   **Responsive Contact System:** Functional, state-managed contact form with real-time validation and submission handling.
*   **Dark Mode Optimized:** Designed primarily with a sleek, dark-themed aesthetic using Tailwind CSS.

---

## 🛠️ Tech Stack

| Technology | Purpose |
| :--- | :--- |
| **Next.js** | React Framework with App Router |
| **TypeScript** | Type-safe development |
| **Tailwind CSS** | Utility-first styling |
| **Aceternity UI** | Advanced Framer Motion components |

## 🚀 Getting Started

### 1. Clone the repository
```bash
git clone [https://github.com/your-username/music-nextjs-app.git](https://github.com/your-username/music-nextjs-app.git)
cd music-nextjs-app
```

### 2. Install dependencies
```Bash
npm install
```
# or
```
yarn install
```

### 3. Run the development server
```Bash
npm run dev
```
Open http://localhost:3000 with your browser to see the result.
